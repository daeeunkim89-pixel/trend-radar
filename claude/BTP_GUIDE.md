# BTP 소재 찾기 가이드 (Claude 예약 작업용)

인스타 @bythepulse(BTP)에 올릴 소재 10개를 매 회차 찾아 Telegram으로 보낸다.
발송 시각(KST): 08, 11, 14, 17, 20시. 회차마다 정확히 10개. 쓸 게 적어도 짜내서 10개를 채운다.
단, 사실이 아닌 것을 지어내지는 않는다. 확인 수준은 항목마다 표시한다.

## 1. BTP가 실제로 올리는 것 (2026-11-23, 공개 게시물 47개 분석)
BTP는 축구 전문 계정이 아니라 "지금 커뮤니티에서 떠드는 것"을 다루는 이슈 계정이다. 축구는 절반 정도.

좋아요가 크게 나온 것:
- 인터넷 인물끼리의 맞대결·독설 (과즙세연 vs 이돈호 로스트, 19,449)
- 레전드 감성·헌정 (호날두 7번 영구 변경, 14,071 / 호나우지뉴 복귀, 8,595)
- 눈으로 보는 장면 (음바페 터닝 원더골, 10,285)
- 논란의 결말·인물 (세무냥이 AI 부정행위 자백, 7,780 / 미미미누 수능 연기 주장, 7,395)
- 스타의 의외 행동 (흐비차 부상 중 트위치 방송, 5,640)

약했던 것: 정부 발표·대책(713), 단순 경기 결과, 한국 대표팀 일반 소식(댓글은 많고 좋아요는 적음).

틀: "○○ 근황 ㄷㄷ", 대비(아모림은 밀란에서 대승 vs 맨유는 참패), 불운 겹치기(두에 부상 + 강도), "엇갈린 반응", 커뮤니티 사연.

유형별 평균 좋아요 (10/18~11/22, 43개):
- 인터넷 인물 논란·맞대결 (과즙세연·미미미누·커맨더지코): 약 9,500 ← 최강
- 해외 슈퍼스타 감성·장면·의외 행동 (호날두·호나우지뉴·음바페·흐비차): 약 7,300
- 논란의 "결말" (세무냥이 자백): 7,780 / 같은 이슈라도 정부 대책·발표는 700~3,700
- 테크·생활 밈 (현대차 캐릭터 테마·테슬라): 약 4,000
- 해외축구 대비·근황 (아모림·토트넘·포체티노·일본): 약 2,800
- 연예 논란 (고경표·래퍼·김원효·성시경): 약 1,900
- 한국 대표팀·선수 소식: 약 2,000 (댓글은 많음, 좋아요는 적음)

왜 터지나: ① 모두가 아는 얼굴 ② 감정 한 방(향수·분노·웃김·통쾌) ③ 사진 한 장·한 줄로 바로 이해 ④ 편 갈리는 댓글 싸움.
4개 중 3개 이상이면 후보 1순위. 정보·발표형(①②없음)은 아무리 중요해도 뒤로.

## 1-1. 유머·커뮤니티 소재도 받는다 (사용자 요청 2026-11-23)
뉴스가 아니어도 포텐에 올라왔거나 올라갈 것 같은 유머·짤·썰·영상도 소재다.
- "올라갈 것 같다" 판단: 올라온 지 1~2시간 안에 추천·댓글이 빠르게 붙는 글, 같은 글이 여러 커뮤니티에 동시에 퍼지는 것.
- 유명인·스트리머·운동선수가 나오는 짤/영상, 대비·반전 구조, "근황" 류가 BTP에 잘 맞는다.
- 출처 표기: 커뮤니티 글 링크 + (있으면) 원본 영상/기사. 원작자·출처 불명 짤은 "출처 확인 필요".
- 일반인 얼굴·신상이 드러나는 것, 성적 대상화(ㅇㅎ), 혐오 조롱은 뺀다.
연예 논란·스트리머·재벌가·테크·주식 폭락도 다룬다. 축구는 해외 슈퍼스타 + 손흥민·한국 선수 연결이 강하다.

사용자가 오늘 좋다고 한 것: 코스피 반토막(4708 마감, 시총 3600조 증발), 브루노 "손흥민·케인과 뛰고 싶었다" 비화.
사용자가 거른 것: 메시 공 투척(BTP가 이미 올림), 중국 U-17·이란 여자축구 같은 한국 팬 관심 밖 소재.

## 2. 매 회차 순서 (사용량 아끼기: 검색 15회 안팎, 본문 열기 20회 안팎)
1. `claude/history.md`에서 최근 3일 보낸 소재를 읽는다. 같은 핵심 사실은 다시 보내지 않는다.
   같은 인물의 새 사실은 무엇이 새로운지 적을 수 있을 때만 보낸다.
2. BTP 최신 게시물 확인: 브라우저로 https://www.instagram.com/bythepulse/ 를 열어 게시물 링크(/p/ID/)를 모으고,
   같은 출처에서 `/p/<ID>/embed/captioned/` 를 fetch 해 캡션 첫 줄을 읽는다. 이미 올라간 소재는 뺀다.
   (로그인 없이 최근 12개까지만 보인다. 막히면 막혔다고 메시지 끝에 적는다.)
3. 커뮤니티 인기글 (유머 포함):
   - 펨코 포텐 https://www.fmkorea.com/best (1~4페이지)와 실시간 검색어. 단, 클라우드(데이터센터 IP)에서는 펨코 보안 시스템이 차단한다. 차단되면 우회하지 말고 아래로 넘어간다.
   - 개드립 인기 https://www.dogdrip.net/dogdrip?sort_index=popular (클라우드에서 열림. 펨코 포텐과 겹치는 글이 많다)
   - CAPTCHA·보안 검사가 뜨는 사이트(더쿠 등)는 풀지 말고 건너뛴다.
   추천수·댓글수·올라온 시각으로 "올라갈 것 같은" 글을 고른다.
4. 네이트 랭킹(네이버는 막혀 있음): 뉴스 많이 본 순, 스포츠 조회순·관심순, 해외축구 관심순.
   WebSearch로 "news.nate.com rank" 류를 찾거나 브라우저로 연다.
5. 후보마다 기사 1개 이상으로 사실 확인. 숫자·발언은 기사 그대로.
6. 신선도: 직전 회차 이후~최근 24시간 안에 새로 나온 사실만. 24시간 넘은 건 새 후속이 있을 때만.
7. 정확히 10개를 고른다. BTP 틀에 맞는 순서로 정렬(사람·장면·대비가 있는 것 먼저).

## 3. 빼는 것
- 이미 BTP에 올라간 것, 최근 3일 history에 있는 것
- 개인의 비극(사망·추락·자살 추정) 자체를 소재로 쓰는 것
- 확인 안 된 수치를 사실처럼 쓰는 것 (커뮤니티 이미지 속 숫자 등)
- 일반인 신상

## 4. 발송 파일 형식 (JSON → 예전 btp 카드 디자인으로 자동 렌더링)
`claude/outbox/YYYYMMDD-HH.json`:
```json
{
  "slot": "11/23 17:00",
  "items": [
    {"category": "해외축구",
     "title": "손흥민 동료 될 뻔했던 브루노 ㄷㄷ \"케인·알리·손흥민과 뛰고 싶었다\"",
     "url": "https://기사링크",
     "why": "2019 토트넘 이적 직전 무산 → 7년 뒤 포체티노와 맨유 재회, 데뷔전 0-4",
     "check": "본문 확인"}
  ],
  "note": "못 본 곳 등 한 줄 (선택)"
}
```
- items는 정확히 10개, 가장 셀 것을 1번(🔥)으로.
- title: BTP 표지 톤 한 줄(근황, ㄷㄷ, 직접 인용). 70자 안쪽.
- why: 왜 터질지 + 핵심 사실 한 줄. 70자 안쪽.
- check: 본문까지 봤으면 "본문 확인"(이 경우 표시 안 됨). 아니면 "제목만 확인 · 무엇 확인 필요"처럼 적는다.
- url: 사실 확인에 쓴 기사 1개.

## 5. 보내는 방법
1. 위 JSON을 `claude/outbox/YYYYMMDD-HH.json` 로 저장 (HH는 발송 시각, 예: 20261123-20.json).
2. `claude/history.md` 맨 위에 이번 회차 10개 제목을 추가.
3. `btp-claude` 브랜치에 커밋·푸시. GitHub Actions(claude-delivery.yml)가 Telegram으로 보낸다.
4. 같은 파일 이름이 이미 있으면 새로 만들지 않는다(중복 발송 방지).

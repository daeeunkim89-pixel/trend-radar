## 원본 검토 순서
1. 후보 제목을 요약하지 말고 실제 대사·행동·자막·전후 변화가 어디에 있는지 찾는다. 긴 영상 전체 시청을 기본값으로 삼지 말고 공개 챕터·자막·타임스탬프에서 해당 구간을 좁힌다.
2. 핵심 동작·반응·결과를 실제 영상 또는 그 구간을 포괄하는 연속 프레임으로 확인한다. 대사 소재는 발화자·앞뒤 문맥을 확인한다. 검색 요약·제목·썸네일·플레이어 로딩을 시청으로 쓰지 않는다.
3. 공개 원본이 막히면 한 번만 실패를 기록하고, 같은 사건의 접근 가능한 공식 클립·당사자 게시물·방송사 자료를 찾거나 다음 후보로 바꾼다. 로그인·보호·지역 제한을 우회하지 않는다.
4. 커뮤니티는 초기 단서와 제목 각도를 배우는 곳이다. 댓글 반응·순위·펨코 게시 여부를 합격선으로 삼지 않는다. 당사자 직접 게시 원문이라면 작성자·날짜·본문 맥락을 확인한다.
5. 시사·사건은 원자료와 당사자 원문을 먼저 찾되, 어제 20시 기준처럼 검증된 구체 사실의 기사형 제작 가능성도 비교한다. 영상이 필요 없는 사실 소재를 “영상을 못 봤다”는 이유로 자동 탈락시키지 않는다.
6. 기사 날짜·목록 수집 시각을 원래 영상/사건의 최초 공개 시각으로 바꾸지 않는다. 장면을 안 봤으면 scene으로 승인하지 않는다.

12시간은 우선 탐색 구간이다. 10개 미달이면 미발송 원본을24시간, 필요시48시간까지 확대하고 실제 공개시각을 밝힌다. 오래된 재게시를 새 장면으로 취급하지 않는다.

최종 후보는 분야·출처별 고정 할당 없이 [어제 20시 기준](btp-reference-20261023-20.md)으로 상대 순위를 매긴다.

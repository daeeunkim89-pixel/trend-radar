# BTP — 매시간 주요 소식 5개
[2026-11-04 최신 편집 기준](btp-news-policy-20261104.md)을 먼저 읽는다. 이 문서가 과거 아이돌·예능·자막·작은 팬 농담 중심 탐색, 매시간 누적 작업, 3시간마다10개와 10개 강제 조건보다 우선한다.

## 목적
스포츠 주요 뉴스를 중심으로 신문1면급 시사 대형 뉴스를 함께 추천한다. 연예는 사회/산업적으로 메이저한 사건일 때만 시사로 포함한다. 일반 연예·자컨·팬덤·예능·무대 디테일·사소한 농담·동네 사건·일반 판결로 채우지 않는다. 100만 조회수를 노릴 대중적 파급력이 목표이며 예측치나 보장은 만들지 않는다.

## 실행
한국시간08~23시 매 정시 클라우드에서5개를 한 메시지로 보낸다. 사용자의 게시 목표 하루10개와 추천 발송 매시간5개는 다르다. PC 전원과 무관하며 실행 사이에는 종료한다. 야간·중복 예약·Instagram 자동 게재·과거 회차 재생·테스트 송신은 금지한다.
최신 main에서 python run_discovery.py --min-refresh-seconds 480를 한 번 실행한다. 의존성 준비→검사→같은 인터프리터 수집을 유지한다. collector는 발견 보조이며 선정 승인이 아니다. 목록의 키워드 순위는 뉴스 가치 검증이 아니다. 별도 네이트 연예 수집을 없애고 스포츠/시사 원문을 먼저 살핀다.
첫 예산10분·검색6·열람24는 시작점이다.5개 미달이면 부족한 스포츠/시사 주요 사건과 공식 경로를 겨냥해 검색4·열람12 단위로 필요한 만큼 확장한다. 이미 정상 수집됐다면 반복 수집보다 원문 검증에 사용량을 쓴다. 설치90초/수집120초 한도는 환경 장애 방지다.
차단 URL 반복·인증 우회·영상 한 편에 고착·전체3000개 덤프·대형 과거 대화 반복·연결 테스트·정각까지 대기·장시간 완료 감시는 하지 않는다. 접근 가능한 공식 발표·독립 보도로 전환한다.

## 추천 완성
주요 스포츠 결과·확정 이적·감독 교체·역사적 기록·중대 징계/부상/논란, 정치·국제·경제·사회 대형 사건을 비교한다. 당사자 발표와 신뢰할 수 있는 원문 본문에서 핵심 새 사실·규모·영향·사건일을 확인한다. 확정 뉴스는 major_news 사실 카드로 충분하며 영상이 핵심일 때만 scene으로 실제 장면을 본다.
처음12시간 우선, 부족하면 미발송24/48시간까지 확장한다. 재기사/재업로드 시간을 원래 사건일로 바꾸지 않는다. generated_at과 verified_at은 실제 검토75분 안, 보지 않은 영상을 시청했다고 쓰지 않는다.
최근7일 sent/uncertain의 event_key·URL·자료·동일 사실과 실제 확인 가능한 BTP 게시를 대조한다. 인물 이름 전체를 검색 제외어로 막지 않는다. 새로운 중대한 후속은 새 사실을 명시하되 같은 사실의 제목 변경은 중복이다.
제목·왜 큰 뉴스인지·원문 링크를 짧게 제시한다. 상세 연예 디테일과 불필요하게 긴 제작 설명은 필요 없다.

## 제출과 완료
[검토본과 승인 발송 절차](btp-editorial.md)의 version2 스키마를 지킨다. 상위5개+검증 예비를 준비한다. UTF-8+마지막 줄바꿈 picks의 SHA256과 version2 report-request를 같은 커밋에 원자 제출한다. 기존 Python workflow만 사용하고 봇 토큰·Chat ID·암호화 state는 읽거나 출력하지 않는다.
production BTP_REQUIRE_COMPLETE=1은 검토 후와 최종 비공개 중복 제외 뒤5개 미달이면 exit3/needs_more_research로 반환한다. 이 경우 잠금을 완료하거나 현황을 성공 발송으로 쓰지 말고 추가 조사한다.10개를 요구하는 오래된 지시는 적용하지 않는다.
제출 후 실제 Actions와 공개 결과에서 stories=5/messages=1/target_met=true를 짧게 확인한다. sent/uncertain 잠금을 초기화하거나 같은 회차에 새 해시로 재발송하지 않는다. 조사/전송의 실제 시간과 검색량을 기록한다. 설정 저장·형식 검사·수집량은 실제 추천 품질/조회수 성과가 아니다.
사용자가 따로 즉시 보충을 요청한 때만 기존 version3 user_requested를 현재 실제 UTC hour로 사용한다. 지금 과거 보충을 반복하거나 별도 Telegram 운영 보고를 보내지 않는다.
